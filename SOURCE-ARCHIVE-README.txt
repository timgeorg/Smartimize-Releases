THIS IS NOT SOURCE CODE
=======================

GitHub attaches a "Source code (zip)" and a "Source code (tar.gz)" archive to every
release, automatically. This file exists so that anyone who opens one of those
archives understands immediately what it is.

WHAT YOU HAVE
-------------
An archive of the PUBLIC repository "timgeorg/Smartimize-Releases". Its entire
content is documentation: this file, README.md, and LICENSE (the proprietary
licence notice for the binaries).

WHAT YOU DO NOT HAVE
--------------------
The Smartimize application source code. It is not in this archive, not in any other
asset of any release, and not anywhere else public.

WHY IT IS LABELLED "SOURCE CODE"
--------------------------------
GitHub generates that archive for every repository and calls it source code, because
for a normal code repository that is what it is. This repository is a download host,
so the archive of it is a download host's documentation — nothing more.

WHERE THE APPLICATION IS
------------------------
https://github.com/timgeorg/Smartimize-Releases/releases — as compiled binaries:

  Smartimize-Setup-x64.exe           Windows installer
  Smartimize-win-x64.zip             Windows standalone
  Smartimize-linux-x64-<ver>.zip     Linux standalone
  SHA256SUMS.txt                     checksums
